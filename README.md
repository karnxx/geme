# parry!
## [Game Link](https://fastestkyo2-real.itch.io/parry) (it can be played on browser)
###  An rpg game, where parrying and timing is the main focus. WASD to move, F to parry stance, SPACE to dodge. In this game, when enemies attack you, lines start drawing on the screen. you have to intercept those lines as quick as possible before they complete and not too close to the start.
